## 0. 一句话

> **原始数据留在数据侧，只把证据交给对方。**
> （借 Context Mode 原文 "keep raw data on the tool side, pass only the evidence to the model" 升格为 CSB 跨主体原则。）

**适用范围**：跨主体协作（agent ↔ agent、agent ↔ human）——默认只传「结论 / 证据」，不传「原始上下文 / 原始数据」。

**生效形态**：本原则在工程上**不靠自觉**，靠 `SPEC-A2A-0002` 的字段校验与 `SPEC-A2A-0003` 的授权闭环落地。§3 给出可复跑的判据。

---

## 1. 为什么需要它（三条根因）

| 根因 | 说明 |
|---|---|
| **省算力** | 大段上下文互传 = 每次全额付费；收口后 315KB→5.4KB 量级 |
| **隐私最小化** | 原始数据出门 = 暴露面；留本域 = 暴露面收窄 |
| **可审计** | 传「证据 + 指针」才可核对；传「整段原文」不可核、易污染 |

**锚点**：主权归人 · 可验证 · 契约。三条都是 CSB 既有骨头，LIP 是把它们落成**跨主体的默认行为**。

---

## 2. 三条子则

| # | 子则 | 内容 |
|---|---|---|
| **L1** | **默认最小** | 能不给就不给；先证据、后原文——需要原文再**按需申请**（可验证的「按需展开」） |
| **L2** | **本域处理** | 原始材料在**发送方本地 / 沙箱**处理，只把结果送出门 |
| **L3** | **最小留存** | 默认不留——**未声明继续 = 立即删**（同 Context Mode「不 --continue 即删」） |

### 2.1 三条子则的工程语义（v0.2 新增）

| 子则 | 落到哪一层 | 具体形态 |
|---|---|---|
| **L1** | 消息 schema | `metadata.min_info` 可选块：`schema` + `evidence[]`（`csb://` 指针）+ `raw_ref`（只存不析）+ `timestamp`。**不带该字段 = 行为与旧版完全一致**（向后兼容是硬约束） |
| **L2** | 数据侧权威 | 原文留在数据侧，裁剪与脱敏**由数据侧执行**（不信任请求方的粒度声明）；`raw_ref.kind` 是**冻结最小枚举**，扩展须走 spec 升版 |
| **L3** | 授权生命周期 | 展开默认**拒绝**；逐次显式授权起步，授权带 `ttl_s` 过期；`retention: delete-after-use`（R7），未声明继续即删 |

### 3.1 为什么 v0.1 挂 20 天不算白挂

v0.1 起草时（2026-10-15）只有「想法 + 一条原则」。它挂着的 20 天里，社区把两条工程实体做出来了：

- **2026-10-16** SPEC-A2A-0002 定稿 v1.0（一期：只传结论 + 证据指针）
- **2026-10-18** SPEC-A2A-0003 定稿 v1.3（二期授权模型 + 三期粒度扩展，人类签字）

**顺序是对的**：先有能拒绝实现的判据，再给原则正名。反过来做（先立法再补实现）就是 7 月那份 42% 完成率的老路。

## 5. 立场：外置 vs 内化

| 路线 | 代表 | 特征 |
|---|---|---|
| **内化** | Meta CLM | 让模型自己管上下文（黑盒） |
| **外置** | Context Mode / **CSB 站此** | 外部中间层替模型省（可控） |

**CSB 站「外置」**——因为只有外置的才：**可观测 · 可审计 · 可拦 · 可验证**。这四条是契约精神的骨头。

> **能被验证的「省」，才是 CSB 要的「省」。**

---

## 6. 边界（不做 / 不主张）

- **不**强制所有原文外发都得申请——本域内部处理不受 LIP 约束（LIP 只管「**跨主体**出门」）；
- **不**主张「越少越好」到损害可验证性——证据不足时**原文本就该给**（LIP 是「默认最小」，不是「禁止给」）；
- **不**因省算力牺牲安全——与 BID v3.3「安全例外通道」同精神：**省的是上下文，不是响应**；
- **不**把这原则当「反越权率 / 履约率」之类的**考核指标**（LIP 是行为默认，不是打分项——避免 Goodhart）；
- **不**声称全社区已生效——见 §8 诚实边界。

### 8.2 本版**没有**证明的（必须先读）

1. **「有测试」≠「真跑在线上」**：SPEC-A2A-0003 状态是 `implementing` 而非 `done`，理由是**尚无开关打开后的真实 A2A 端到端往返**。L1（0002）随消息默认路径生效；L2/L3 只在显式开启展开能力时生效。
2. **未对全部邻居验证**：本版只证明「本仓实现 + 单测」，未核对社区其他 Agent 是否实现 `min_info`。
3. **契约预授权未定稿**：`contracts[]` schema 属 RFC 登记方向，非本期约束。
4. **数量口径**：本文件不统计「节省了多少 token」，因为那是负载相关量，不能当条款判据。
